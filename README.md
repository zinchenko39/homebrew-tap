# Homebrew tap for Conserva

```sh
brew install --cask zinchenko39/tap/conserva
```

Conserva is a macOS menu bar app that keeps things to read later in glass jars on the bottom of your screen: https://github.com/zinchenko39/conserva

Releases are signed ad hoc and not notarised yet, so the first time macOS will say the app cannot be checked. Either open it with right-click → Open, or install with `--no-quarantine`:

```sh
brew install --cask --no-quarantine zinchenko39/tap/conserva
```
